# Source And Asset Provenance

This records existing provenance for the unaudited Helper 1.4.37 transfer, not
an independent public-release decision. Project-owned original application,
scripts, native interoperability helpers, SWB macros and icon artwork are
declared GPL-3.0-only. Agent-assisted changes are made for the same project.

The nine paired SWB/SWPs are BackupAssembly_v1, BOM_v19, BOM_v19_ROfriendy,
CNCDXF_v1/CNCDXF_final_v1, CrawlScrews_v1, DXF_v16, DXF_v16_ROfriendy, PDF_v1
and Radius_v9. SWPs were generated locally from corresponding reviewed sources;
the private iteration compiler is excluded. Generic identifiers and editable
settings replace deployment-specific names. Native profiles, folder caching,
embedded metadata, multibody capture and stock-depth changes are project work.

Update Center behavior/protocol was inspected in the public ExcelsisViewer
repository at commit `3abc6190c5755aea5367e7614136403979064f5a`. Viewer is
AGPL-3.0-or-later. Helper's protocol implementation and popup are independently
authored; no Viewer module, engine or reference file is included or vendored.
Helper's license is unchanged, with no new package dependency.

CrawlScrews remains an opt-in diagnostic with a privacy prompt. No reports,
screenshots, customer fixtures, private presets or personal data are transferred.
No vendor program, SDK DLL, SOLIDWORKS/SolidCAM binary or custom font is included.

Lucide copy/folder glyphs and a folder-plus variant use the shared ISC notice in
licenses/Lucide-ISC.txt. The packaged notice heading/icon list predates that
variant and needs public-release review. DWG thumbnail-table parsing translates
the MIT DwgThumbnailReader algorithm with upstream identity in the notices.
The machining engine has authored formulas and factual normalized data with
source references, not vendor catalogues, logos, PDFs or calculator output.

Electron/Chromium, Node packages and checksum-pinned NSIS/Elevate inputs retain
their licenses; THIRD_PARTY_NOTICES.md and docs/DEPENDENCY_LICENSES.md record
versions, declared metadata and source references. Independent licensing,
redistribution and provenance review remains required before publication.
