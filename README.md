# Excelsis Helper

Excelsis Helper is an open-source Windows workflow companion for SOLIDWORKS.

This new standalone repository is intentionally **product-empty for now**:
only the project landing page, public project information, and its license are
present. Product source, installers, and release assets will be added only
after a separate release review.

- Project site: https://simonsystem609.github.io/ExcelsisHelper/
- ExcelsisView: https://simonsystem609.github.io/ExcelsisViewer/
- Support and issue reports: https://github.com/simonsystem609/ExcelsisHelper/issues
- Excelsis3D development discussion: https://discord.gg/uJrSBQm68

Please do not upload confidential customer or CAD files to public issues.
